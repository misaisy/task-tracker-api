# Task Tracker API

Минимальный сервис для отслеживания задач.

## Требования

- Python 3.11+
- pip

## Локальный запуск

### 1. Клонируйте репозиторий
```
git clone https://github.com/misaisy/task-tracker-api.git
cd task_tracker_api
```

### 2. Создайте и активируйте виртуальное окружение
```
python -m venv venv
venv\Scripts\activate
```

### 3. Установите зависимости
```
pip install -r requirements.txt
```

### 4. Настройте переменные окружения

Скопируйте файл-образец:
```
cp .env.example .env
```
При необходимости отредактируйте `.env`, указав свои значения.

### 5. Запустите сервер

Запуск по умолчанию стоит в `dev` 

Для того чтобы сменить режим на `test` или обратно на `dev` необходимо ввести `$env:APP_ENV="test"` или `$env:APP_ENV="dev"` соответственно

Команда для запуска:
```
python run.py
```

### 6. Проверьте работоспособность

Откройте браузер и перейдите по адресу:
`http://127.0.0.1:8000/health`

Или выполните в терминале:
```
curl http://127.0.0.1:8000/health
```
Ожидаемый ответ:

`{"status":"ok"}`

Swagger UI доступен после запуска:
`http://127.0.0.1:8000/docs`
