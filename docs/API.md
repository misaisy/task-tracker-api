## <a id="tasks"></a>Задачи

### <a id="get-tasks"></a>GET /tasks

Возвращает список задач с фильтрацией, сортировкой и пагинацией.

**Query-параметры:**

| Параметр     | Тип       | По умолчанию | Ограничения                        | Описание               |
|--------------|-----------|--------------|------------------------------------|------------------------|
| `status`     | `string`  | -            | -                                  | Фильтр по статусу      |
| `priority`   | `string`  | -            | -                                  | Фильтр по приоритету   |
| `sort_by`    | `string`  | `created_at` | `created_at`, `priority`, `status` | Поле для сортировки    |
| `sort_order` | `string`  | `desc`       | `asc`, `desc`                      | Направление сортировки |
| `page`       | `integer` | `1`          | ≥ 1                                | Номер страницы         |
| `page_size`  | `integer` | `20`         | 1–100                              | Размер страницы        |

**Ответ `200 OK`:**

```json
{
  "items": [
    {
      "id": 1,
      "title": "Пример задачи",
      "description": "Описание задачи",
      "priority": "high",
      "status": "TODO",
      "created_at": "2026-05-27T12:00:00Z",
      "updated_at": "2026-05-27T12:00:00Z",
      "closed_at": null,
      "owner_id": 1,
      "asignee_id": null
    }
  ],
  "total": 1,
  "page": 1,
  "page_size": 20,
  "pages": 1
}
```


### <a id="post-tasks"></a>POST /tasks

Создаёт новую задачу.

**Тело запроса:**

| Поле	        | Тип                 | Обязательное | По умолчанию  | Ограничения             |
|---------------|---------------------|--------------|---------------|-------------------------|
| `title`       | `string`	          | Да	         | -	           | 1-200 символов          |
| `description` | `string` или `null` | Нет	         | `null`	       | До 1000 символов        |
| `priority`	  | `string`	          | Нет	         | `"medium"`	   | `low`, `medium`, `high` |
| `status`      | `string`	          | Нет	         | `"TODO"`	     | -                       |
| `owner_id`	  | `integer`           | Нет	         | `null`    	   | user существует         |

**Ответ `201 Created`:**
```json
{
  "id": 1,
  "title": "Новая задача",
  "description": "Описание задачи",
  "priority": "high",
  "status": "TODO",
  "created_at": "2026-06-10T12:00:00Z",
  "updated_at": "2026-06-10T12:00:00Z",
  "closed_at": null,
  "owner_id": 1,
  "assignee_id": null
}
```

**Ошибки:**

| Код	  | Когда                                                        |
|-------|--------------------------------------------------------------|
| `404`	| `owner_id` указан, но пользователь не найден                 |
| `422`	| Невалидные поля (пустой title, недопустимый priority и т.д.) |


### <a id="patch-taskstask_id"></a>PATCH /tasks/{task_id}`

Частично обновляет задачу.

**Path-параметры:**

| Параметр  | Тип	      | Описание  |
|-----------|-----------|-----------|
| `task_id` | `integer` | ID задачи |

**Тело запроса (все поля опциональны):**

| Поле	        | Тип	                | Ограничения             |
|---------------|---------------------|-------------------------|
| `title`	      | `string` или `null` | 1–200 символов          |
| `description` |	`string` или `null` | До 1000 символов        |
| `priority`    | `string` или `null` | `low`, `medium`, `high` |
| `status`      | `string` или `null` | -                       |

**Правила PATCH:**

| Ситуация	                                                               | Поведение                    |
|--------------------------------------------------------------------------|------------------------------|
| Поле не передано	                                                       | Не меняется                  |
| Поле передано с новым значением                                          | Обновляется                  |
| `description: null`                                                      | Сбрасывается в `null`        |
| `title: null`	                                                           | Ошибка `422`                 |
| `id`, `created_at`, `updated_at`, `closed_at`, `owner_id`, `assignee_id` | Игнорируются (менять нельзя) |
| Задача архивирована                                                      | Ошибка `409`                 |

**Ответ `200 OK`: `TaskResponse`**

**Ошибки:**

| Код 	| Когда                                  |
|-------|----------------------------------------|
| `404`	| Задача не найдена                      |
| `409`	| Попытка изменить архивированную задачу |
| `422`	| Невалидные поля или `title: null`      |

## <a id="general"></a>Общая информация

### <a id="query-params"></a>Query-параметры

Query-параметры используются для фильтрации, сортировки и пагинации в `GET`-запросах.

**Общие правила:**

* Все query-параметры опциональны (если не указано иное)

* Параметры пагинации: `page` (начиная с 1) и `page_size` (максимум 100)

### <a id="status-codes"></a>Status-коды

| Код   | Название	            | Когда используется                                     |
|-------|-----------------------|--------------------------------------------------------|
| `200` | OK	                  | Успешный GET, PUT, PATCH                               |
| `201` | Created	              | Успешный POST (создание ресурса)                       |
| `400` | Bad Request  	        | Некорректный JSON                                       |
| `404` | Not Found  	          | Ресурс не найден                                       |
| `409` | Conflict  	          | Конфликт состояния (архивирование архивного, дубликат) |
| `422` | Unprocessable Entity  | Ошибка валидации полей                                 |
| `500` | Internal Server Error | Неожиданная ошибка сервера                             |

### <a id="error-format"></a>Формат ошибок

Все ошибки возвращаются в едином формате:

**Ошибка "не найдено" (404):**
```json
{
  "error_code": "TASK_NOT_FOUND",
  "details": "Task with id=999 not found"
}
```

**Ошибка конфликта (409):**
```json
{
  "error_code": "CONFLICT",
  "details": "Task is already archived"
}
```

**Ошибка валидации (422):**
```json
{
  "error_code": "VALIDATION_ERROR",
  "details": [
    {
      "loc": ["body", "title"],
      "msg": "ensure this value has at least 1 characters"
    }
  ]
}
```

**Ошибка сервера (400):**
```json
{
  "error_code": "MALFORMED_JSON",
  "details": "Request body contains invalid JSON"
}
```
